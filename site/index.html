The story

09:14

Northgate Bank runs AI agents over commercial loan files. An engineer with database access opens the audit table and changes one row. An agent run that had approved a two-million-pound facility now reads as declined.

09:16

Nothing looks wrong. No alert fires. The dashboard is green, because the dashboard is reading the same table that was just edited.

09:31

The audit store goes down for forty minutes. A contractor asks for administrator rights. The platform refuses: no record, no grant. A departing employee's access is revoked in the same window — that completes, and its record waits in a queue, because blocking a removal during an outage would be worse than the outage.

Next day

The auditor runs one command. It prints divergence at 217. She does not ask the bank for anything, and she does not need their cooperation to check the rest.

The engineer could recompute every hash in the table afterwards. It would not help: a signed copy of the end of the chain was already written somewhere the bank's own administrators cannot delete.

Two questions, two apps

Neither question is enough on its own. A record that is provably unchanged is still useless if the action never reached it; a complete record is worthless if anyone with a database login can rewrite it.
